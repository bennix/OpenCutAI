AI / UNDER THE HOOD

模型、密钥与生成边界。

当前通过 ZenMux 统一接入，Base URL：https://zenmux.ai/api/v1。在「设置 → ZenMux AI」保存自己的 ZenMux API Key；无需分别填写 OpenAI、Google 或 MiniMax 密钥。模型调用由 ZenMux 按账户额度计费，本地剪辑无需订阅。

用途应用内预设模型 ID接口 / 限制
视频minimax/minimax-h3-max/videos · 单段 5–15 秒 · 480p / 768p（默认）
视频google/gemini-omni-1.1-flash-preview/interactions · 时长与画幅作为创作偏好，输出不保证严格一致
图片openai/gpt-image-2.5-flare
openai/gpt-image-2.5-sunburst
google/gemini-3.1-flash-image		图片生成 / Google generateContent 路由；输出尺寸由模型决定
分镜与剪辑规划openai/gpt-6.1-sol
anthropic/claude-sonnet-5.5		/chat/completions · 生成可编辑分镜与剪辑计划

以上是当前代码中的预设 ID，实际可用性取决于 ZenMux 模型目录、账户权限与余额。支持编辑模型列表。分镜单段为 1–30 秒，并按已配置的模型上限拆分；普通视频请求校验为 1–120 秒，但服务商通常有更低上限。未列出的模型没有统一分辨率保证；AI 生成分辨率与项目 / 导出分辨率是不同设置。

每段可选择将末帧作为下一段的首帧参考；该功能需要所选路由支持图片参考，并不能保证人物或画面完全连续。生成提示词及参考素材会发送给服务商，密钥保存在本地且不进入项目导出。

FIND YOUR WORKFLOW

为什么选择 OpenCut AI？

产品主要定位OpenCut AI 的选择
CapCut面向广泛创作者的剪辑、模板与发布体验面向需要开放源码、自带 API Key 和可编辑 AI 分镜流程的用户
DaVinci Resolve专业剪辑、调色、音频后期与视觉特效聚焦录屏 → AI 分镜生成 → 时间线编辑的一体化轻量流程；专业调色 / VFX 仍更适合 Resolve
OpenCut Classic本项目继承的开源编辑器基础增加 AI 分镜、占位与重试、可选末帧续接，以及录屏和系统音轨工作流

这是工作流定位说明，不是功能或性能评测。OpenCut AI 基于 OpenCut Classic，并保留 MIT 许可及原项目声明。
